# skills

Agent skills by **wesbrek**.

## Skills

| Skill | Description |
|-------|-------------|
| [`open‑pr`](./plugins/open-pr) | Open a GitHub PR for the current change — writes the title/description from the diff and embeds screenshots/videos inline via [`pr-media`](https://github.com/MatteoSchifano/gh-pr-media). |

## Install

One command, works across 20+ agents (Claude Code, Cursor, Copilot, Windsurf, and more):

```bash
npx skills add wesbrek/skills
```

Then invoke with `/open-pr`, or just ask your agent to open a pull request.
